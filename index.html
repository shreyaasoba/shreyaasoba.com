The problem I solve, in one box

Medical records arrive as scans, faxes and free text, and every lab writes the same test differently. My job is turning that into clean, coded data a doctor can rely on, and flagging what doesn't add up.

Type a test name the way a report might, and watch it resolve. It runs entirely in your browser.

How it decides
Standard code (LOINC)
Cheap exact lookup first, then fuzzy matching, and only the genuinely ambiguous cases go to a language model or a person. When nothing is close, it declines rather than guesses. This demo uses 20 public LOINC codes; the production service I built maps to more than 59,000.
