The problem, in one box

Every lab writes the same test differently. Type one the way a scanned report might. It runs entirely in your browser.

Cascade
Standard code (LOINC)
The shape of the idea: try a cheap exact lookup first, then fuzzy matching, and only hand the genuinely ambiguous cases to a language model, or to a person. When nothing is close enough, decline rather than guess. Twenty reference codes from the public LOINC table here; the production service I built maps to more than 59,000.
02

What I build

At Nephrolytics AI I build the data and model layer behind kidney care: getting patient lab history out of whatever format it arrives in, and making it correct.

Lab names to standard codes

A Go service that maps free-text lab names from EMR feeds and scans to 59K+ LOINC codes at 98% accuracy across 4M+ observations. A prior-mapping cache and skip patterns keep most records off the LLM path.

GoLOINCLLMs

Model evaluation

Benchmarked four LLMs stage by stage for document classification and summarization, so each step uses its best performer: 20% lower classification cost and 8% higher accuracy.

evalsLLM-as-judgecost

Implausible-value detection

Per-code bounds set from an audit of every unit and reference range, so an impossible OCR value goes to clinician review instead of into a patient's risk score.

GoDjangoReact

Document AI for real-world inputs

PDF, TIFF and image ingest, multi-column dates, batch-breaking context overflows, and prompts reworked with practicing physicians. Benchmarked LlamaParse against AWS Textract on its failure cases.
